## ⭐ Why ForceLearn?

> "The best free resource for learning Salesforce from scratch. Worth 10,000+ dollars in certification training." - Community Review

ForceLearn is the **open-source community platform** for mastering Salesforce - the world's #1 CRM. Whether you're starting your Salesforce journey or preparing for architect certification, ForceLearn has you covered.

### Key Features

- 📚 **Structured Learning Paths** - Admin, Developer, and Architect tracks
- 🎯 **100+ Learning Modules** - From basics to advanced concepts
- 📱 **Mobile Responsive** - Learn anywhere, on any device
- 🔄 **Always Updated** - Latest Salesforce features and best practices
- 💯 **Free Forever** - No paywalls, no accounts required
- 🌐 **108+ Pages** - Comprehensive documentation and blogs

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/bhanuprakashsfdc/forcelearn.git

# Navigate to the project
cd forcelearn

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
